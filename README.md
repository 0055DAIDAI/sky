# 外卖订餐项目 

## 项目简介

外卖订餐是一个基于 Spring Boot 的外卖订餐系统，采用前后端分离架构。该项目是一个经典的 CRUD 练手项目，涵盖了后端开发的核心技术栈和业务场景，适合学习和实践企业级应用开发。

## 技术栈

### 后端框架
- **Spring Boot** 2.7.3 - 核心框架
- **MyBatis** 2.2.0 - ORM 持久层框架
- **MyBatis-Plus** - 增强工具

### 数据库与缓存
- **MySQL** - 关系型数据库
- **Redis** - 缓存数据库

### 安全与认证
- **JWT (jjwt 0.9.1)** - 令牌认证
- **拦截器** - 权限控制

### 工具库
- **Lombok** 1.18.20 - 简化代码
- **FastJSON** 1.2.76 - JSON 处理
- **PageHelper** 1.3.0 - 分页插件
- **Druid** 1.2.1 - 数据库连接池
- **Knife4j** 3.0.2 - API 文档工具
- **AspectJ** 1.9.4 - AOP 面向切面编程
- **Apache POI** 3.16 - Excel 导入导出
- **阿里云 OSS** 3.10.2 - 对象存储


### 环境要求
- JDK 1.8+
- Maven 3.6+
- MySQL 5.7+
- Redis 5.0+
## 核心特性

### 1. 自动填充功能
通过自定义注解 `@AutoFill` 和 AOP 切面，实现创建时间、更新时间、创建人、修改人等字段的自动填充。

### 2. 全局异常处理
统一的异常处理器 `GlobalExceptionHandler`，处理各类业务异常并返回标准化响应。

### 3. JWT 令牌认证
- 管理端和用户端分离的令牌机制
- 拦截器验证令牌有效性
- 基于 ThreadLocal 的用户上下文

### 4. Redis 缓存
- 缓存店铺营业状态
- 缓存验证码
- 缓存用户订单等信息

### 5. WebSocket 支持
实现服务端向客户端的消息推送，用于订单状态变更通知。

### 6. 定时任务
- 订单超时未支付自动取消
- 来单提醒
- 派送提醒
